Festival de Cine de Málaga

Presentación

El Festival de Cine de Málaga reúne cada año a profesionales, directores y aficionados para disfrutar de algunas de las mejores producciones cinematográficas nacionales e internacionales.

Durante tres días se proyectarán películas, cortometrajes y documentales, además de celebrarse diferentes actividades relacionadas con el mundo del cine.

Programación

  1. Viernes
    • Inauguración
    • Película de apertura
  2. Sábado
    • Cortometrajes
    • Cine documental
    • Película internacional
  3. Domingo
    • Cine español
    • Gala de clausura
